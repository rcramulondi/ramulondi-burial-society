Design notes: A visible key up top explains the * / "optional" convention once, so admins never have to guess or be trained. On mobile, the 3 lowest-priority optional fields (email, address, alternate contact) start collapsed behind "Add more details" — this shortens the phone form to only what's needed to save a record, while keeping the data reachable in one tap. Two-column rows (ID/contact, contribution/start date) automatically stack to one column under 480px. Try the "Add more details" button.
